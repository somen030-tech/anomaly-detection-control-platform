# Anomaly Detection Control Platform

## Project Overview

An end-to-end financial anomaly detection and analytics platform designed to identify unusual patterns in financial transactions and support data-driven risk monitoring.

## Objectives

- Build reliable financial data processing pipelines.
- Engineer financial and time-series features.
- Identify unusual financial patterns and deviations.
- Develop analytical controls and monitoring outputs.
- Apply Python, SQL, statistics, and machine learning to financial risk analytics.

## Technology Stack

- Python
- Pandas and NumPy
- Scikit-learn
- Statistical and time-series analysis
- SQL
- Git and GitHub

```bash

```

```bash
python src/features/01_financial_feature_engineering.py
```
